# Satish Randive — Personal Portfolio

A responsive personal portfolio website for `satishrandive.com`.

This version intentionally does **not** publish client names or employment/work-experience details.

## Run locally
Open `index.html` in a browser, or use a simple local server.

## Deploy
Recommended: push this folder to GitHub and import the repository into Vercel. Then add `satishrandive.com` as the custom domain in Vercel and update DNS records according to Vercel's instructions.
